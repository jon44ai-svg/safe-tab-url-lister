Privacy Policy

Last updated: November 25, 2026 — applies to version 1.2.1 and later.

Short version: Safe Tab URL Lister does not send data to the developer. Saved tabs stay in local extension storage. The only optional network calls go to a Laya server you run at 127.0.0.1:8000 or localhost:8000, and those calls omit query strings and fragments.

What the extension reads

When you open the popup, the extension reads the following information about your currently open tabs, using Chrome's/Firefox's/Safari's built-in tabs permission:

  • URL and page title
  • Tab position (index) and window ID
  • Tab ID and the ID of the tab that opened it, if applicable
  • Numeric tab group ID, if the tab is part of a group
  • Last-accessed timestamp
  • Whether the tab belongs to an incognito/private window

Each of these fields only appears in the extension's output if you explicitly check its corresponding option in the popup. With every option unchecked, only the URL is included.

What the extension does with that data

It lists open tabs and, when you save them, writes title, redacted URL, tags, and folders to chrome.storage.local on this device. The original URL is stored only if you opt in. Copy still puts the export on the clipboard. Treat that text as sensitive. An optional local Laya request sends title, host, and path only — never the query or fragment.

What the extension does not do

  • No analytics, telemetry, or crash reporting, and no requests to the developer's servers
  • No cookies. storage is used only for tabs you save on this device
  • host_permissions are limited to http://127.0.0.1:8000/* and http://localhost:8000/*. The extension does not read page DOM on other sites
  • A background service worker only asks Chrome to open the side panel
  • No third-party or CDN-hosted scripts
  • No accounts, sign-in, or user identifiers of any kind

Permissions

Chrome requests tabs, storage, and sidePanel, plus loopback host access for local Laya. Firefox and Safari use tabs and storage with the same loopback hosts. Nothing is sent to a third-party analytics service.

Open source

The full source code is public and MIT-licensed, so this policy can be verified directly against the code rather than taken on faith: github.com/muminkoykiran/safe-tab-url-lister.

Changes to this policy

If this policy ever changes, the "Last updated" date above will change and the update will be noted in the project's changelog.

Contact

Questions about this policy or the extension's data handling can be raised as a GitHub issue, or privately via GitHub's private vulnerability reporting for security-sensitive matters.
